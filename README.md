# 🏹 Vijayadashami — A Cinematic Digital Experience

**An immersive digital celebration of Vijayadashami (Dussehra), celebrating the eternal victory of good over evil, light over darkness, and Dharma over Adharma.**

Vijayadashami is a premium, cinematic web experience that brings the timeless spirit of the *Ramayana* to life through modern web technologies, immersive animations, interactive storytelling, and a rich visual aesthetic inspired by Indian heritage.

Designed with a royal palette of **Wine, Gold, and Ivory**, this experience blends ancient devotion with contemporary digital artistry to create a journey that feels both sacred and cinematic.

---

## ✨ Features

### 🪔 1. Cinematic Opening Ritual
- An immersive opening sequence inspired by traditional Hindu rituals.
- An interactive Diya that responds to user interaction.
- A radiant ring of fire that builds anticipation.
- A divine visual introduction inspired by Lord Ram.

### 🌊 2. WebGL Fabric Transition
- A custom GLSL shader powering a flowing, fabric-inspired visual transition.
- Dynamic, wave-like motion that creates a sense of depth and movement.
- Sacred Sanskrit shlokas integrated into the transition.
- A seamless visual bridge between the opening ritual and the main experience.

### 🔥 3. Interactive Experiences
- Custom cursor rings for a more immersive browsing experience.
- Magnetic buttons with subtle interactive movement.
- Drifting embers that add atmosphere and cinematic depth.
- An interactive Diya that flares and emits sparks on interaction.

### 🎨 4. Divine Artwork
- AI-generated concept illustrations inspired by Lord Ram, Laxman, and Ravan.
- A visual narrative inspired by the epic of Ramayana.
- Carefully curated colors, lighting, and compositions that reflect the grandeur of Indian mythology.

### 🎬 5. Smooth Scrolling & Parallax
- Scroll-driven animations powered by GSAP and ScrollTrigger.
- Cinematic reveal effects and layered parallax movement.
- Carefully choreographed transitions between sections.
- Fluid motion designed to enhance the storytelling experience.

### 📱 6. Responsive Design
- Optimized layouts for desktop, tablet, and mobile devices.
- Adaptive typography, spacing, and visual compositions.
- A consistent experience across different screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) — preferably a current LTS version
- npm — included with Node.js
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/shailcodes/vijayadashami.git
```

### 2. Navigate to the Project Directory

```bash
cd vijayadashami
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Visit the local development URL:

```text
http://localhost:5173
```

You're all set! Explore the experience and witness the digital celebration of Vijayadashami. 🏹
